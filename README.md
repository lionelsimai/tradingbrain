# TradingBrain

A swing-trading **decision-support** engine for stocks and crypto (ManaNova Pte.
Ltd.), built with an unusually honest validation and safety apparatus. It screens
a universe, scores conviction across six pillars, builds defined-risk trade plans,
red-teams its own calls, and **refuses to trade live until a battery of gates is
green**. It is informational, not financial advice.

## Start here: validate & see the verdict
```
python3 -m scripts.validate_all          # runs everything, writes FINAL-REPORT.md
python3 -m scripts.validate_all --skip-tests   # faster
```
Then read **FINAL-REPORT.md**. Today's honest verdict: **gauntlet REJECTED,
go-live BLOCKED** — correct, because the system has no live track record yet.

## The everyday commands
```
python3 -m scripts.recommend                  # today's ranked picks + trade plans
python3 -m lab.go_live                         # the 7-gate "can we trade live?" verdict
python3 -m lab.gauntlet                        # institutional validation scorecard
python3 -m backtest.monte_carlo --method block # drawdown / risk-of-ruin distribution
python3 -m scripts.export_app                  # bundle picks for the web app (schema-valid)
python3 ops/serve.py --once                    # one paper cycle (the 24/7 loop, one pass)
```

## How it fits together
- **Engine** (`scripts/recommend.py`) — turns detected setups into ranked,
  defined-risk recommendations. Conviction is capped at "moderate" until real live
  trades exist; it never invents price levels.
- **Memory** (`scripts/collective/memory.py`) — regime-aware recall of the real
  trade track record, with lesson decay. Verified to never misreport (`lab/memory_metrics.py`).
- **Validation** — data-quality gate, look-ahead proofs (`lab/validate.py`),
  Monte Carlo (`backtest/monte_carlo.py`), the institutional gauntlet
  (`lab/gauntlet.py`: PBO, Deflated Sharpe, skill-vs-beta, break-even, capacity, Kelly).
- **Go-live authority** (`lab/go_live.py`) — 7 gates, enforced in the live order
  path and fail-closed. Picks can't reach real money until every gate is green.
- **Self-improvement loop** (`loops/improve.py`) — one change at a time, logged in
  `export-state/experiments.csv`, with kept-changes verified against the live edge.
- **App** (`app/`) — a Next.js + Supabase front end that ingests the engine's
  output (see `app/README.md`). Reviewed, not yet run against live services.

## The one honest caveat
Everything here is **validation and safety scaffolding around an edge that is not
yet proven live**. The track record is replay on a survivor-only universe, so the
numbers are an optimistic ceiling. The only things that move the verdict are
running it in **paper mode** to build a real record and adding a **survivorship-free
(delisted-inclusive) universe** — not more code.

_Markets risk total loss of capital. Past or backtested performance does not
predict future results._
